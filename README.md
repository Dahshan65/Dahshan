# رواق الخط العربي / وائل دهشان ✒️

منصة تعليمية تفاعلية مفتوحة المصدر مخصصة لعرض وشرح دروس فنون الخط العربي (خط النسخ، خط الرقعة، اتصال الحروف والقنطرة) مع شواهد الضبط وقواعد الإعراب للغة الضاد.

---

## 🌟 مميزات المنصة

- **واجهة عربية أصيلة:** تصميم متجاوب (RTL) مستوحى من جماليات المخطوطات والزمرد التعليمي.
- **مشغل فيديو مرن:** يدعم تضمين مقاطع يوتيوب مباشرة وروابط الفيديو السحابية بصيغة MP4.
- **إدارة الدروس محلياً:** إمكانية إضافة دروس جديدة وتخزينها تلقائياً داخل المتصفح عبر `localStorage`.
- **تصنيف وبحث فوري:** تصفية الدروس حسب الأبواب الفنية والبحث السريع في العناوين والشواهد الإيضاحية.
- **الوضع الليلي (Dark Mode):** إمكانية التبديل بين المظهر الفاتح والمظهر الداكن لراحة العين أثناء المشاهدة والتطبيق.
